Same purple, readable chart. Four additions, each answering a question the shipped one cannot: a right-hand scale + gridlines (how much?), dated x-axis (when?), a now line, dot and headline value (where am I?), and solid past vs dashed future (what is measured vs guessed?). Small dots mark the doses that cause each rise.

That last one is where this goes further than Shotsy, whose entire line is dashed: the left of the marker is computed from doses you actually logged, the right is a projection from your schedule. Drawing them the same way would let a projection pass as history.

Not free: the range control needs real wiring and a backend window parameter — today it is decorative and only ±7 days of curve exists, so Month/90 days/All have nothing behind them.
