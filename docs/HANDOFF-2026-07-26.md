## Working conventions (learned the hard way)

- Design work extends `pepta-frontend/design-lab/index.html` — the design
  hub, using its exact classes. Never design in isolation; never start from
  scratch. Sign-off gate before code.
- `.device` frames grow with content — partial frames need
  `min-height:726px` or they collapse to a stub.
- Sibling native Modals: close first, navigate in `onDismissed`
  (the barcode-freeze fix).
- Citation discipline: no sourced range → no warning. Never invent numbers
  for research peptides.
- Copy: user-set, never "optimal" or recommended. Approved drugs say
  "Label dosing"; everything else says "Community protocol."
- Typographic apostrophes (`’`) throughout — a test caught straight ones.
- Backend deploys must rebuild `@pepta/shared` (a stale deployed `dist`
  caused the RevenueCat webhook 400).
